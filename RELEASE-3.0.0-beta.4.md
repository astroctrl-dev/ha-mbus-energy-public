# v3.0.0-beta.4 — mobile Web UI refinement

- Compact active diagnostics with visible active warnings, expandable details and source-labelled consolidated attributes. Conflicting values remain distinct.
- Readable timestamps without fractional seconds, retaining UTC or local offset semantics.
- Expandable clock and history help and historical fault detail; shorter, wrapping history table headings.
- Grouped meter operations and administration; completed migration displayed as status.

Presentation-only update. Physical primary-address writing remains disabled. Protocol diagnostics remain opt-in and disabled by default. Resume is limited to the current app session. This is an isolated-test preview, not a production release. Back up app data before upgrading; do not downgrade with pending recovery state. Physical and mobile acceptance remain outstanding.
