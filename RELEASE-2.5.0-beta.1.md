# v2.5.0-beta.1

Public beta, distributed through the ordinary App Store repository. Stable v2.4.0 remains available as a GitHub release.

Four interface languages, localized configuration, Excel temperature selection, native Home Assistant temperature-difference support. Existing MQTT sensor identities and canonical values retained. Communication timing and meter handling unchanged.

Known limitations: some legacy labels and technical messages remain untranslated. Physical validation and existing Home Assistant statistics verification are pending. Back up before testing. Do not run two apps against one adapter or MQTT identity. Update the existing app through the ordinary repository; do not add a separate beta repository entry.
