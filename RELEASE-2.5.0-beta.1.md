# v2.5.0-beta.1

Public opt-in beta. Stable v2.4.0 remains on the default branch.

Four interface languages, localized configuration, Excel temperature selection, native Home Assistant temperature-difference support. Existing MQTT sensor identities and canonical values retained. Communication timing and meter handling unchanged.

Known limitations: some legacy labels and technical messages remain untranslated. Physical validation and existing Home Assistant statistics verification are pending. Back up before testing. Do not run two apps against one adapter or MQTT identity. A separate beta repository entry may create a separate app identity; it is not an in-place upgrade of the stable app.
